# Design reference for UI work

`ops/reference/design-md/brands/<brand>/DESIGN.md` holds token-plus-prose analyses of 84 brand design systems (Linear, Stripe, Vercel, Notion, Apple and more; vendored from VoltAgent/awesome-design-md, MIT). When a bead builds or restyles a UI, read the README there and one or two close brands first; borrow structure, never identity, and a rig's own design conventions always win.
